# iM금융그룹 AX 추진 현황

그룹 CEO가 계열사별 AX 확산, 업무 혁신과 성과를 점검하는 경영 대시보드 데모. **실행 상태·성과·LLM 경로는 가상 데이터**입니다. iM뱅크의 29개 주무부서와 110개 업무 에이전트 제목·정의는 사용자가 제공한 실제 Long List를 반영합니다. 외부 LLM이나 실제 사내 시스템에 연결하지 않습니다.

GitHub 저장소: https://github.com/yalkongs/agentmonitoring

화면은 차콜·슬레이트 기반의 **Group AX / CEO Overview** 테마를 사용합니다. 내부 LLM은 블루, 외부 LLM은 앰버로 구분하고, 제공받은 로고는 헤더에 한 번만 작게 표시합니다. 로고는 제공된 원본에서 하단 글자와 흰 배경을 제거한 투명 PNG 심벌을 사용하며, 원래의 민트색·그라데이션을 표시합니다. 중앙에는 AI 업무 적용률을, 계열사에는 각각의 적용 수준을 표시합니다. 등록 에이전트 수는 후보·목록 규모를 설명하는 보조 지표입니다.

## Vercel 배포

운영 배포는 Vercel의 `weoncheol-hwangs-projects/agentmonitoring` 프로젝트를 사용합니다. Vite를 빌드해 `dist/`를 배포하며 별도 서버나 외부 LLM 연결은 필요하지 않습니다.

```sh
# 최초 환경 연결 (Vercel CLI 설치 및 로그인 필요)
vercel link --yes --project agentmonitoring --scope weoncheol-hwangs-projects
# 테스트와 빌드 통과 후 즉시 운영 배포
npm run deploy
```

프로젝트 업데이트를 완료하면 검증 후 즉시 Vercel 운영 배포까지 수행합니다. 이 지속 지침은 `AGENTS.md`에 기록되어 있습니다. 소스는 GitHub 저장소(https://github.com/yalkongs/agentmonitoring)에 공개되어 있지만, Vercel과 Git 연동은 하지 않아 push만으로 자동 배포되지 않습니다. 운영 주소는 배포 결과의 Production alias에서 확인합니다.

## 대형 TV 모드

1280px 이상 가로 화면에서는 TV 전용 화면이 기본으로 열립니다. `?view=tv`로 직접 열거나 기존 화면의 **TV 모드** 버튼을 사용하세요. 기존 검색·필터 화면은 **분석 화면** 버튼 또는 `?view=dashboard`로 열 수 있습니다.

- 1920×1080 / 2560×1440 / 3840×2160에서 전체 화면을 한 번에 표시합니다. 브라우저 배율 100%를 권장합니다.
- 계열사 포커스는 8초마다 바뀌며 80초 동안 10개 회사를 모두 보여줍니다. 하단 카드도 현재 회사에 맞춰 5개씩 전환합니다.
- 실시간 숫자는 3초 간격의 합성 데이터를 0.9초간 부드럽게 보간합니다. 구체, 입자 궤적, LLM 경로, 업무 단계, 하단 활동 자막이 움직입니다.
- **전체 움직임 일시정지**는 숫자·구체·워크플로·자막·자동 순환을 함께 멈춥니다. **계열사 자동 순환 일시정지**는 현재 회사를 고정하고 실시간 데이터는 계속 갱신합니다.
- `Space`: 전체 일시정지/재개, `←` / `→`: 계열사 이동, `F`: 전체화면. 브라우저 전체화면은 `Esc`로 종료합니다.
- 전체화면에서는 지원되는 브라우저에서 Screen Wake Lock을 요청합니다. 지원되지 않아도 TV 화면은 정상 동작합니다.
- OS 동작 줄이기 설정을 존중합니다. 구체·궤적·자막·자동 순환을 정지하고 수치는 즉시 갱신합니다.
- 토큰 파형, 실행 단계, 자막 이벤트는 합성 시각화이며 실제 로그를 재생한 것이 아닙니다. TV의 집계 기간은 이번 달로 고정합니다.

## 계열사 상세 화면

TV 네트워크의 회사, 하단 계열사 카드, 좌측 **계열사 상세 보기**, 분석 화면의 계열사 표를 누르면 별도 상세 화면으로 전환됩니다. 그룹 AX 현황 버튼과 브라우저 뒤로가기로 기존 화면에 돌아갑니다. 다른 계열사로 바꾸는 선택기도 제공합니다.

iM뱅크 직접 접속: https://im-intelligence-observatory.weoncheol-hwang.chatgpt.site/?view=affiliate&affiliate=bank

- 원본: **주무부서별 업무 에이전트 목록 v0920**, AX추진부, 2026.09, 31쪽. 부서별 표와 합계의 29개 부서·110개 항목을 대조했습니다.
- 왼쪽 부서 필터 → 가운데 검색·페이지 목록 → 오른쪽 에이전트 정의·시연 지표. 110개 전체를 6개씩 조회합니다. 모바일에서는 선택한 에이전트 상세로 이동합니다.
- 검색은 제목·ID·부서·정의에 적용됩니다. 추론 경로·시연 상태 필터, 절감 시간순 정렬, 기간 선택, 갱신 정지, 전체화면을 지원합니다.
- 에이전트 정의와 원문 쪽수는 실제 목록에 기반합니다. **우선순위와 도입 시점은 원문 공란**이므로 미기재로 표시합니다. Long List는 실제 구축·운영 중임을 뜻하지 않습니다. BANK ID는 화면용 식별자입니다.
- 모든 실행 상태·완료 업무·시간·토큰·비용은 합성 시나리오입니다. 에이전트별 합과 부서별 합은 기존 iM뱅크 집계에 일치하며 검색·필터에 따라 상단 지표도 함께 바뀝니다.
- 기존 iM뱅크 가상 에이전트 148개를 실제 목록 110개로 교체했습니다. 그룹 검토·등록 목록은 388개(은행 원문 110개 + 타 계열사 가상 278개)입니다. 타 계열사의 상세 화면은 실제 목록 수신 전까지 가상 데이터로 표시됩니다.
- `?view=affiliate&affiliate=bank&agent=BANK-110&from=dashboard`처럼 직접 링크하거나 새로고침해도 같은 회사·에이전트로 열립니다.

## 실행

Node.js 22.18+ 권장.

```sh
npm install
npm run dev
```

http://localhost:5173 에서 확인합니다. 대형 모니터는 1920×1080 또는 3840×2160, 브라우저 배율 100%를 권장합니다. 우측 상단 **발표 모드**로 전체화면을 전환하며 Esc로 종료합니다. 1440×900 이하 노트북은 필요에 따라 세로 스크롤합니다.


## 데이터 기준

기간은 데모 기준일 **2026-09-21**에 고정되어 있으며 우측 시계는 실제 KST입니다. 오늘·월간·연간은 각각 1일·21일·192일 상당의 합성 업무량입니다. 연간 일수는 영업일 달력의 재현이 아닌 명시적인 데모 계수입니다.

시간은 계열사별 완료 업무 × 순 절감 분(1.7–5.4분)으로 계산합니다. 검토·재작업은 순 절감 분에 차감된 것으로 가정합니다. 업무 가치(시간 × 35,000원)는 현금 절감이 아니며, 인월(시간 ÷ 160)은 감축 인원이 아닙니다.

내부 토큰 비중은 계열사별 42–95%입니다. 내부 100만 토큰당 1,800원, 외부 8,200원의 예시 원가를 적용하며 실제 공급자의 가격이 아닙니다. 토큰 풀 배분은 내부 72:28, 외부 65:35의 데모 구성입니다. 캐시 비용을 별도로 차감하지 않는 단순 혼합 원가 모델입니다. 업무 가치/추론 비용은 개발·플랫폼 비용을 포함하지 않으므로 ROI가 아닙니다.

완료 건수·시간·가치·토큰·비용의 계열사 합은 그룹 합과 일치합니다. 운영 에이전트는 시점 재고이므로 기간 변경에 따라 늘어나지 않습니다. 그룹 성공률은 전체 완료 / 전체 시도로 계산합니다. 증감률·추이 분포·LLM p95·캐시·보안 상태는 고정 데모 값입니다.

활동 피드는 집계 원장을 재생한 것이 아닌 별도의 합성 이벤트입니다. 상세 창이 열리거나 브라우저 탭이 숨겨지면 갱신을 멈춥니다. 새로고침하면 초기 시나리오로 돌아갑니다. 데이터 저장이나 실제 에이전트 제어는 수행하지 않습니다.

## CEO의 점검 관점

- 시스템 제목은 **iM금융그룹 AX 추진 현황**, 화면 제목은 **그룹 AX 추진 현황**입니다.
- 계열사별 업무 적용률과 생산성 성과를 우선하며, 시스템 실행 상태는 보조 정보로 제공합니다.
- 메인 분석 화면의 **추진 점검 포인트**는 선택 범위의 적용률이 가장 낮은 회사, 시스템 실행 기능의 연계 범위, 재작업 없는 완료율을 연결합니다. 새로운 목표나 실제 추진 실적을 가정하지 않습니다.
- 중앙 적용률은 등록 에이전트 수로 가중한 시연값이며 목표 달성률과 구분합니다. 활동 피드는 업무 혁신 사례와 건당 시간 확보 가정을 보여줍니다.

## 효율 및 MCP 관리 지표

메인 상단에는 순 절감 업무시간, 업무 처리시간 단축률, 재작업 없는 완료율, 성공 업무 1건당 비용을 표시합니다. 비용은 실패·재시도 추론, 업무 연계·도구, 검토·재작업·실패 대응을 포함하며 구축·개발비는 제외합니다. 기존 추론 비용 및 시간 가치와 구분합니다.

내부 MCP 패널은 핵심 업무 기능 연계율, 시스템 연계 업무 완료율, MCP 활용 에이전트 비중, 공통 도구 재사용을 표시합니다. 화살표 버튼으로 시스템별 조회·실행 검증 수, 공통 도구와 산정 기준을 볼 수 있습니다. MCP는 실제 접속하지 않으며 시스템·기능·실행·승인 상태가 모두 가상입니다.

- 기능 연계는 2026.09.21 시점, 활용 에이전트와 도구 재사용은 최근 30일의 고정 시연 스냅샷입니다.
- 업무 완료·호출·오류·정책 차단은 선택 기간, 승인 대기는 현재 시점의 진행 상태입니다.
- 그룹 비율은 분자·분모를 합산하고, 재사용 도구는 ID를 중복 제거합니다. p95는 호출 분포를 합쳐 계산합니다.
- TV의 효율 안내 및 MCP 상세를 열면 시뮬레이션이 멈춥니다. 닫으면 이전 갱신 상태로 돌아갑니다. CSV에도 새 지표와 집계 범위를 포함합니다.

## 검증

```sh
npm test
npm run build
# 최초 브라우저 설치
npx playwright install chromium
# dev 서버 실행 후
node scripts/verify.mjs
node scripts/verify-tv.mjs
node scripts/verify-affiliate.mjs
```

이미 설치된 Chromium을 사용하려면 `PLAYWRIGHT_EXECUTABLE_PATH`를 지정합니다. 다른 서버 포트는 `DEMO_URL`로 지정합니다.

검증 스크립트는 그룹 합계·환산식·기간·에이전트 ID 무결성, 실시간/정지, 필터, 검색, 검토 대기, 상세 창, CSV, 발표 모드와 FHD/4K/모바일 레이아웃을 확인합니다. `artifacts/`에 화면 캡처를 저장합니다.

## AX 가치 대형모니터 화면 · /1/

https://agentmonitoring.vercel.app/1/ 에서 효율성과 고객가치 중심의 독립 대형모니터 화면을 볼 수 있습니다. 기존 `/` 화면과 스타일·동작은 유지됩니다. 새 화면은 어두운 저채도 배경의 한 화면 레이아웃입니다. 1280×720, FHD, QHD, 4K에서 스크롤 없이 효율성·고객가치·업무 사례·경영 판단을 표시합니다. 계열사 순위와 자동 수치 갱신은 없습니다.

- 그룹/계열사와 일간/월간/연간 선택은 URL에 저장되며 새로고침해도 유지됩니다.
- 효율성은 기존 합성 원장의 tick 0을 사용합니다. 그룹에서는 업무시간을 합산하고, 계열사 간 개선율 비교나 종합 점수는 표시하지 않습니다.
- 고객 성과는 관측 자료가 없어 ‘미수집’으로 표시합니다. 업무 사례의 기대 효과와 검증할 지표는 측정 설계 예시입니다.
- 업무 사례는 화살표로 수동 전환하고, 연결 근거와 데이터·산정 기준은 대화상자로 확인합니다. 전체화면 버튼 또는 F키를 지원합니다. 얇은 연결선 효과만 천천히 움직이며 정지 버튼·동작 줄이기·대화상자 열림을 반영합니다.
- `npm run test:briefing`으로 범위·기간·새로고침·모달·반응형 화면 및 기존 화면 분리를 검증합니다. `DEMO_URL`로 검사할 호스트를 지정합니다.
- `1/index.html`, `src/briefing.ts`, `src/briefing.css`가 독립 화면이며 `vite.config.ts`에서 두 HTML 진입점을 함께 빌드합니다.
